# pi-心理 · 心理健康对话 Agent

基于 [pi-agent-core](https://github.com/earendil-works/pi) 框架构建的心理健康支持对话助手。

## 功能

- **情绪分析**：实时分析用户情绪状态，识别焦虑、抑郁、压力等 7 种情绪
- **危机检测**：四级风险检测（none/low/medium/high），高危时自动触发干预流程
- **CBT 结构化交互**：完整的认知重构流程——思维记录表、苏格拉底式提问、认知扭曲识别（10种）、行为激活、情绪日记
- **知识检索**：覆盖弗洛伊德精神分析、CBT、依恋理论、防御机制等 16 个主题
- **会话持久化**：本地 JSON 存储，支持恢复历史对话

## 会话管理命令

| 命令 | 说明 |
|------|------|
| `/历史` | 查看所有历史会话 |
| `/新建` | 创建新会话（自动保存当前） |
| `/继续 <编号>` | 继续指定编号的会话 |
| `/清除` | 清除当前会话历史 |
| `退出` | 结束对话并保存 |

启动时会自动列出历史会话，可选择继续或新建。

## CBT 交互流程

当用户表达困扰时，Agent 按以下结构化流程引导：

```
共情探索 → 识别自动思维 → 识别认知扭曲 → 苏格拉底式提问
    ↓
形成替代思维 → 行为激活 → 情绪追踪
```

### 认知扭曲识别（10种）
灾难化、非黑即白、过度概括、个人化、情绪推理、心理过滤、读心术、应该陈述、标签化、放大缩小

### 新增 CBT 工具

| 工具 | 功能 |
|------|------|
| `cbt_thought_record` | 创建完整思维记录表，自动检测认知扭曲并生成苏格拉底式提问 |
| `cbt_behavioral_activation` | 根据精力水平制定行为激活计划（低/中/高） |
| `cbt_mood_journal` | 记录和分析当天情绪日记，发现情绪规律 |
| `cbt_guide` | 识别认知扭曲，提供针对性重构引导 |

## 数据存储

会话文件保存在 `~/.pi-心理/sessions/` 目录下，格式为 JSON。

## 知识库内容

### 弗洛伊德经典著作（9 篇）
- 《梦的解析》— 显梦/隐梦、梦的工作机制
- 《日常生活的心理病理学》— 口误、遗忘的潜意识意义
- 《超越快乐原则》— 死本能/生本能、强迫性重复
- 《文明及其不满》— 文明与本能压抑的悖论
- 《自我与本我》— 结构模型（本我/自我/超我）
- 《哀悼与忧郁》— 正常哀悼 vs 病理抑郁
- 《图腾与禁忌》— 俄狄浦斯杀父假说
- 《疑病一篇》— 转换癔症、压抑机制
- 《精神分析导论》— 防御机制、神经症理论

### CBT 专题（2 篇）
- 基础原则：认知三角、10种认知扭曲、干预步骤
- 常用技术：思维记录表、苏格拉底提问、行为激活、暴露疗法等

### 其他心理学主题（3 篇）
- 防御机制（10种详解）
- 依恋理论（四种类型）
- 情绪调节策略

## 安全边界

- 明确声明「我不是专业心理咨询师」
- 不给出诊断建议，只提供情感支持和引导
- 危机场景自动推荐专业热线
- 会话内容仅本地存储，不上传云端

## 快速开始

```bash
# 安装依赖
npm install

# 配置 API Key（编辑 .env 文件）
# LLM_API_KEY=your_key_here

# 运行（开发模式）
npm run dev

# 或运行编译后的代码
npm start
```

## 项目结构

```
src/
├── index.ts              # CLI 入口（readline 交互 + 会话管理）
├── agent.ts              # Agent 初始化（OpenAI 兼容流式客户端）
├── session.ts            # 会话持久化（读写 ~/.pi-心理/sessions/）
├── system-prompt.ts      # 系统提示词（含CBT完整交互流程）
└── tools/
    ├── sentiment.ts      # 情绪分析工具
    ├── crisis.ts         # 危机检测工具
    ├── cbt-guide.ts      # CBT认知扭曲检测（基础版）
    ├── cbt-session.ts    # CBT结构化流程（思维记录表/行为激活/情绪日记）
    └── knowledge.ts      # 知识库检索工具（动态读取markdown）
knowledge/
├── base-knowledge.md     # 基础心理学知识
├── freud/                # 弗洛伊德经典著作（9篇）
├── cbt/                  # CBT理论与技术（2篇）
└── general/              # 其他主题（3篇）
```

## 技术栈

- **运行时**：Node.js >= 22.19
- **Agent 框架**：pi-agent-core (TypeScript)
- **LLM 客户端**：pi-ai + OpenAI SDK（OpenAI 兼容接口）
- **UI**：Node.js readline（CLI 模式）
- **持久化**：本地 JSON 文件（无外部数据库依赖）
