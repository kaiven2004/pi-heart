# 《自我与本我》（The Ego and the Id, 1923）

## 结构模型的提出
这本书标志着弗洛伊德从"地形学模型"（意识/前意识/无意识）转向"结构模型"（自我/本我/超我）。

## 三大心理结构

### 1. 本我（Id / Das Es）
- 心理中最原始的部分，完全无意识。
- 遵循"快乐原则"：追求即时满足，不考虑现实和道德。
- 包含基本本能：性本能（Libido）和攻击本能。
- 本我没有时间概念，没有逻辑，没有否定。

### 2. 自我（Ego / Das Ich）
- 从本我中发展出来，承担调解功能。
- 遵循"现实原则"：评估现实条件，延迟满足。
- 使用防御机制保护个体免受焦虑。
- 自我是本我的"代理人"，但不是它的主人。

### 3. 超我（Superego / Das Über-Ich）
- 内化的社会规范和道德标准。
- 包括"良心"（惩罚违规）和"自我理想"（奖励符合）。
- 超我往往比现实更严厉，导致过度的内疚。
- 超我的形成与俄狄浦斯情结的解决相关。

## 三者关系
- 自我夹在本我（欲望）、超我（道德）、现实（限制）三者之间。
- 心理健康的关键：自我足够强大，能够协调三者冲突。
- 神经症：自我被本我或超我过度压制。

## 经典比喻
弗洛伊德将自我比作骑手，本我比作马——骑手试图控制马的方向，但马的力量往往更强大。

## 对心理 Agent 的意义
当用户表达"我知道应该...但我就是控制不住"，可以引导其理解本我与自我的冲突，并探索如何增强自我功能。
