# 心理学知识库

## 焦虑 (Anxiety)

焦虑是面对威胁时的正常反应。适度的焦虑有助于我们应对挑战，但当焦虑过度或持续存在时，可能影响日常生活。

### 常见症状
- 心跳加速、呼吸急促
- 肌肉紧张、头晕
- 过度担忧、难以集中注意力
- 睡眠困难

### 自助应对技巧
1. **4-7-8 呼吸法**：吸气4秒，屏气7秒，呼气8秒，重复3-4次
2. **接地技术**：5-4-3-2-1 感官法，将注意力拉回当下
3. **渐进式肌肉放松**：依次收紧和放松各肌肉群
4. **规律运动**：有氧运动可显著降低焦虑水平

## 抑郁 (Depression)

抑郁情绪和抑郁症是不同的概念。短暂的情绪低落是正常的，但如果持续两周以上且影响日常生活，可能发展为抑郁症。

### 常见症状
- 持续的情绪低落、空虚感
- 对曾经喜欢的事物失去兴趣
- 睡眠和食欲改变
- 精力下降、疲劳感
- 自我评价过低

### 自助应对技巧
1. **行为激活**：从小事开始，逐步恢复日常活动
2. **运动**：每周至少150分钟中等强度运动
3. **社交连接**：与信任的人保持联系
4. **正念冥想**：关注当下，不加评判

## 压力 (Stress)

压力是身体对挑战或威胁的自然反应。长期压力会损害身心健康。

### 管理策略
1. **时间管理**：番茄工作法，合理分配任务
2. **设定边界**：学会说"不"
3. **放松训练**：冥想、深呼吸、瑜伽
4. **社会支持**：与朋友家人保持联系

---

## 认知扭曲 (Cognitive Distortions)

认知扭曲是不合理的思维模式，会加剧负面情绪。常见的认知扭曲包括：

1. **灾难化**：过度夸大负面后果
2. **非黑即白**：用极端的两极化看待事物
3. **过度概括**：从单一事件得出普遍结论
4. **个人化**：将外部事件过度归因于自己
5. **情绪推理**：把感受当作事实
6. **"应该"陈述**：用严格的标准要求自己或他人

### 认知重构步骤
1. 识别自动负性思维
2. 识别认知扭曲类型
3. 寻找证据支持或反对这个想法
4. 形成更平衡的替代想法
